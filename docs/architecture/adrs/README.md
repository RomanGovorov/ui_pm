## ADR Template

Each ADR follows this structure:
1. **Title**: ADR-NNN: Short descriptive title
2. **Status**: Proposed | Accepted | Deprecated | Superseded
3. **Context**: The forces at play, the problem description
4. **Options Considered**: Alternatives evaluated with pros/cons
5. **Decision**: The chosen option with rationale
6. **Consequences**: Positive, negative, and neutral outcomes
