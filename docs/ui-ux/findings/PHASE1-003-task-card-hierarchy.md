# PHASE1-003: Карточки задач — визуальная иерархия и читаемость

**Severity:** Serious (ухудшает usability для всех пользователей)
**Area:** TaskCard
**Component:** `src/components/TaskCard.tsx`

## Описание

Компонент TaskCard отображает задачу, но визуальная иерархия информации недостаточна. Отсутствует достаточная дифференциация между элементами для быстрого сканирования доски стейкхолдером.

### Выявленные проблемы

#### 1. Приоритет и статус смешаны

Приоритет показан badge-ом сверху, но нет визуального индикатора статуса задачи — он определяется только позицией карточки в колонке. Это создаёт когнитивную нагрузку при поиске задач по приоритету.

#### 2. Название задачи

Текущая спецификация (компонент-spec): bold, 14px. В коде: `text-sm font-semibold` (~14px). Но:
- Нет максимального ограничения длины — длинные названия могут занимать 3+ строк
- `line-clamp-2` применён только к описанию, а не к названию
- В архитектуре указано truncation, но это не реализовано

#### 3. Аватар ответственного

Использует hash-based выбор цвета (`getAvatarColor`), что работает, но:
- Нет fallback для имён из одного слова — получаем одну букву вместо двух
- Размер `w-6 h-6` + `text-[10px]` — допустимо, но маловато для быстрого распознавания
- Имена русских участников содержат пробелы — хэш может быть непредсказуемым

#### 4. Date display

Relative дата форматирована локально, но:
- Нет hover-тултипа с полной датой (например, `toLocaleDateString` при ховере)
- Дата отображается в правом углу, но визуально отделена от имени — можно перепутать

#### 5. Hover и active состояния

```tsx
className={`... transition-all hover:shadow-md cursor-default`}
```
- `cursor-default` — карточка не кликабельна в v1 (соответствует PRD: ручное перетаскивание позже). Это корректно, но `cursor-default` не добавляет ценности — можно опустить.
- Нет `focus-visible` стиля — клавиатурная навигация не имеет визуальной обратной связи
- `hover:shadow-md` — мягкая тень, но недостаточно выражена для обнаружения ховера в тёмной теме

#### 6. Padding и spacing

Карточка: `p-3.5` (14px padding). По спецификации компонент-спека — «rounded card with border». Размеры допустимы, но:
- Gap между priority badge и заголовком: отсутствует явный margin-bottom (используется `mb-2` на badge, что даёт 8px)
- Gap между description и footer: `mb-3` на desc + автоматический margin — достаточно

### Рекомендации

1. **Truncate title:** Добавить `line-clamp-1` на заголовок карточки
2. **Focus ring:** Добавить `focus-visible:ring-2 focus-visible:ring-blue-500` для клавиатурной навигации
3. **Tooltip на дату:** Wrap date span в title attribute или tooltip component
4. **Avatar fallback:** Улучшить `getInitials` для однословных имён (повторить первую букву)
5. **Hover enhancement:** Усилить `hover:border-gray-600` и добавить subtle background shift
6. **Priority consistency:** Приоритетная цветовая система уже определена в `priorityColors` — убедиться что в production code используется тот же набор токенов

## WCAG Reference

- **WCAG 1.4.4 Resize Text** (AA) — текст масштабируется без потери содержания
- **WCAG 1.4.11 Non-text Contrast** (AA) — визуальная информация различима
